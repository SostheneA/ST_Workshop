The Challenge

Discrete dots in a fluid ocean

The input

Data at discrete sampling locations:

\[ s_i = (\text{Longitude}, \text{Latitude})_i \]

Each tow, station, or transect is one point in space.

The illusion

Standard regression treats each \(s_i\) as independent — as if every point were surrounded by a vacuum.

Biological truth

Fish populations form a continuum. A 500 kg catch at point \(A\) implies similar density 500 m away. Independence is a modelling fiction we must repair.

Tobler’s First Law

“Everything is related to everything else, but near things are more related than distant things.”

— Waldo Tobler, 1970

Like weather: if it rains at your house, it is probably raining at your neighbour’s. Fish density behaves the same way.

Why we cannot ignore it

Spatial autocorrelation clumps the error term \(\varepsilon\). The consequences:

  • biased fixed-effect estimates (covariates absorb spatial structure they did not cause)
  • overconfident standard errors → too-narrow confidence intervals
  • inflated Type-I error in hypothesis tests

The Gaussian Random Field

The invisible sheet

A Gaussian Random Field (GRF) is a stochastic process where any finite collection of points follows a multivariate normal distribution:

\[ \boldsymbol{\omega} = \big(\omega(s_1), \ldots, \omega(s_n)\big) \sim \mathcal{N}_n(\mathbf{0}, \boldsymbol{\Sigma}) \]

Imagine an elastic sheet draped over the study area:

Peaks

High density pushes the sheet upward.

Valleys

Low density lets it sink.

Smooth slopes

Stretchiness ensures continuity between neighbours.

The Matérn covariance — rules of the sheet

The texture and stiffness of the GRF. For two points at distance \(d_{ij} = \lVert s_i - s_j \rVert\):

\[ \operatorname{Cov}\!\big(s_i, s_j\big) \;=\; \sigma^{2}\,\frac{1}{2^{\nu-1}\Gamma(\nu)}\,(\kappa\, d_{ij})^{\nu}\,K_{\nu}(\kappa\, d_{ij}) \]

Range — \(r\)

Distance beyond which spatial correlation effectively vanishes.

\[r = \sqrt{8\nu}\,/\,\kappa\]

Marginal SD — \(\sigma\)

Magnitude of spatial variability — the wave height of the sheet.

\(K_\nu(\cdot)\) is the modified Bessel function of the second kind; \(\nu\) controls smoothness (commonly fixed at \(\nu = 1\) in 2-D SPDE work).

The Computational Trick

The “Big N” problem

A continuous GRF requires inverting a dense \(n \times n\) covariance matrix.

Step Cost
Build \(\boldsymbol{\Sigma}\) \(\mathcal{O}(n^{2})\) memory
Invert / Cholesky \(\boldsymbol{\Sigma}\) \(\mathcal{O}(n^{3})\) time
Likelihood evaluation per iteration \(\mathcal{O}(n^{3})\)

With \(n \approx 5{,}000\) tows, this breaks any laptop — and surveys routinely hit \(10{,}000\)+ records.

We need a representation of the GRF that is continuous in space but sparse in computation.

The SPDE approach — the spider web

Lindgren, Rue & Lindström (2011) showed that a Matérn GRF is the stationary solution of a stochastic partial differential equation:

\[ (\kappa^{2} - \Delta)^{\alpha/2}\,\big(\tau\,\omega(s)\big) = \mathcal{W}(s) \]

Solve it on a triangulated mesh — a finite set of knots:

Knots

Field values are computed only at triangle vertices.

Barycentric interpolation

Within each triangle, values are linearly blended.

Result

Sparse precision matrices replace dense covariance — fast and scalable.

Designing the mesh — precision vs. performance

Inner zone

  • high triangle density
  • in the data-rich region
  • high precision, slower

Outer buffer zone

  • larger triangles
  • prevents edge leakage and numerical instability
  • cheap to compute

R Lab — build your mesh

library(sdmTMB)

mesh <- make_mesh(
  data    = catch_df,
  xy_cols = c("X", "Y"),
  cutoff  = 15            # km between knots
)

plot(mesh)

The cutoff argument controls knot spacing — smaller values yield finer meshes.

Tip

Rule of thumb: target the cutoff at roughly 1/5 of your expected spatial range \(r\).

Putting It Together

Integrating the field into the model

The spatially explicit linear predictor adds the GRF term \(\omega(s_i)\) to the fixed effects:

\[ \log(\mu_i) \;=\; \underbrace{\beta_0 + \beta_1\,\text{Depth}_i + \beta_2\,\text{Temp}_i}_{\text{fixed effects}} \;+\; \underbrace{\omega(s_i)}_{\text{latent spatial field}} \]

Fixed effects

Measured covariates — depth, temperature, sediment.

\(\omega(s_i)\)

Absorbs unmeasured drivers: hidden currents, habitat structure, social behaviour.

INLA / sdmTMB

Fast (approximate) Bayesian inference in R — no MCMC required.

A reproducible fit in sdmTMB

library(sdmTMB)

fit <- sdmTMB(
  formula = catch_kg ~ depth_s + temp_s,
  data    = catch_df,
  mesh    = mesh,
  family  = tweedie(link = "log"),
  spatial = "on"
)

tidy(fit, effects = "ran_pars", conf.int = TRUE)
#> term        estimate  conf.low  conf.high
#> range       42.6      31.2      58.1
#> phi          1.18      1.05      1.32
#> sigma_O      0.91      0.74      1.12

Equivalent INLA workflow: inla.spde2.pcmatern() → inla.stack() → inla().

The resulting Magic Map

What you gain

  • Corrected uncertainty — confidence intervals reflect true spatial patchiness; no more overconfident predictions.
  • Prediction anywhere — estimate density at any \((\text{Lon}, \text{Lat})\), including unsampled locations.
  • Honest covariate effects — fixed effects are no longer contaminated by spatial structure.
  • Diagnostic value — the shape of \(\hat{\omega}(s)\) reveals the missing covariate you have not yet measured.

Predict on a new grid

grid <- expand.grid(
  X = seq(xmin, xmax, by = 2),
  Y = seq(ymin, ymax, by = 2)
)

preds <- predict(
  fit,
  newdata     = grid,
  return_tmb_object = TRUE
)

# Posterior mean + SE per cell
head(preds$data[, c("est", "est_se")])
